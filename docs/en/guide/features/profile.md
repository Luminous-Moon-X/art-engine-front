# User Center

## Feature Overview

A self-service maintenance entry point for the currently logged-in account, used to update the profile and reset the login password.

How to access: top bar → avatar → "User Center". This page is not shown in the menu.

## Page Content

| Area | Content |
| --- | --- |
| Left profile card | Avatar, Username, bio, Email, Phone, Address, personal tags |
| Right basic information | Username (read-only), Nickname, Gender, Email, Phone, Address, bio, personal tags |

Click "Edit" to enter edit mode; save after making adjustments to apply them; "Cancel" discards this round of changes.

## Reset Password

Top bar → avatar → "Reset password"; fill in the current password, the new password, and the confirm password. After a successful submission, the system automatically logs out, and you need to log in again with the new password.

If this is your first login, or an administrator has reset your password, the system requires you to change the password first right after logging in.

## Notes

- The nickname, email, phone, and other information in the profile are displayed in the top bar user menu and the profile card
- Personal tags can be left empty and are used to identify information such as position and responsibilities
