# 什么是 Art Engine?

Art Engine 是一套面向企业与多租户场景的中后台管理系统。提供后台管理系统中常见的功能，包括租户管理、用户管理、组织管理、角色管理、权限管理、字典管理等。<br/> 项目兼具设计美学与高效开发，适合快速二次开发搭建网站和管理系统。采用MIT开源协议，协议友好没有版权风险，可以放心用于闭源商业项目。

## 核心能力

| 能力             | 说明                                                                         |
| ---------------- | ---------------------------------------------------------------------------- |
| 登录与认证       | 账号密码登录、多租户选择登录、登录态维护、修改密码与强制改密、退出登录、锁屏 |
| 账号管理         | 账号新增 / 编辑 / 删除、分配角色、归属组织、启用状态、重置密码               |
| 组织管理         | 树形组织架构维护，作为账号归属与按组织筛选的依据                             |
| 角色管理         | 角色维护，角色是权限分配的基本单位                                           |
| 功能权限管理     | 菜单 + 按钮两级权限，可按角色 / 部门 / 用户授权，权限标识精确到具体操作      |
| 多租户           | 租户与租户套餐管理，租户之间数据隔离，套餐控制租户可用的功能范围             |
| 数据字典         | 统一维护下拉选项与状态标签，业务无需硬编码枚举                               |
| 文件管理         | 对象存储配置与文件的上传、浏览、下载、删除                                   |
| 日志管理         | 登录日志、菜单日志、接口日志，支持条件检索与审计                             |
| 规则管理         | 业务规则与系统参数的集中配置，调整无需发版                                   |
| 知识库与 AI 问答 | 文档上传、解析、向量化，结合 AI 对话实现企业知识问答                         |
| 个人中心         | 个人资料维护与登录密码修改                                                   |

## 主要特性

- **权限精细**：菜单级与按钮级权限，后端校验、前端联动控制显隐
- **多租户**：租户数据隔离，套餐按功能权限授权
- **界面灵活美观**：浅色 / 暗黑 / 跟随系统主题、自定义主题色、四种菜单布局、多标签页
- **开箱即用**：提供完整的后台管理系统功能，开箱即用

## 运行环境

- 浏览器：Chrome、Edge、Firefox、Safari 等现代浏览器
