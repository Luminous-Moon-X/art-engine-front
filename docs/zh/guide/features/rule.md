# 规则管理

## 功能概述

集中维护系统中的业务规则与参数（如阈值、开关、开关项、文本配置），把原本写死在代码里的可变参数交由后台配置，调整时无需发版。

## 规则信息字段

| 字段 | 说明 |
| --- | --- |
| 规则名称 | 规则的中文名称 |
| 规则编码 | 业务引用规则时的唯一标识 |
| 规则值类型 | 规则值的数据类型，取自数据字典（如字符串、数字、布尔、文本等） |
| 规则值 | 规则的具体取值，输入控件会随「规则值类型」自动切换（输入框 / 数字框 / 开关 / 多行文本） |
| 是否启用 | 停用后业务不再读取该规则 |
| 备注 | 补充说明 |

## 页面操作

| 操作     | 说明                                                                               |
| -------- | ---------------------------------------------------------------------------------- |
| 查询     | 按规则名称、规则编码筛选                                                           |
| 新增规则 | 填写编码、名称、值类型与规则值                                                     |
| 编辑     | 修改规则名称、值类型、规则值、启用状态与备注；切换值类型时规则值会重置，需重新填写 |
| 删除     | 删除规则                                                                           |
| 排序     | 创建日期支持排序                                                                   |

## 典型用途

- **业务开关**：功能灰度、开关项由后台统一控制
- **参数配置**：分页条数、上传大小上限、超时时间等
- **文案配置**：提示语、公告文案等可变内容
