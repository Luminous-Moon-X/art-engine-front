# 知识库与 AI 问答

## 功能概述

知识库用于沉淀企业文档：文档上传后经**解析**与**向量化**处理，即可作为 AI 问答的知识来源。系统提供知识库管理、文档管理，以及顶栏的 AI 对话窗口。

## 知识库管理

以卡片形式展示知识库（封面、名称、描述、创建时间），支持按知识库名称搜索与分页浏览。

| 操作       | 说明                                                                 |
| ---------- | -------------------------------------------------------------------- |
| 创建知识库 | 填写知识库名称（必填，最多 100 字）、描述（最多 500 字），可上传封面 |
| 编辑       | 修改名称、描述与封面                                                 |
| 删除       | 删除知识库                                                           |
| 查看文档   | 点击卡片打开右侧抽屉，管理该知识库下的文档                           |

## 文档管理

在知识库抽屉中维护文档：

| 项       | 内容                                                           |
| -------- | -------------------------------------------------------------- |
| 搜索条件 | 文档名称                                                       |
| 列表列   | 文档名称、文档类型、解析状态、向量状态、上传时间、上传人       |
| 上传文档 | 支持 pdf、doc、docx、txt、md、xls、xlsx、ppt、pptx、wps 等格式 |
| 解析文档 | 触发文档内容解析，解析完成后可查看与编辑内容                   |
| 编辑内容 | 以 Markdown 方式查看并修改解析后的内容（需解析完成）           |
| 处理向量 | 把文档内容向量化，作为 AI 问答的知识来源（需先完成解析）       |
| 删除     | 删除文档                                                       |

文档处理流程：**上传 → 解析 → 处理向量 → 参与 AI 问答**。解析状态与向量状态都会在列表中展示（待处理、处理中、已完成、失败）。

## AI 问答

入口：顶部导航栏右侧的聊天图标。能力包括：

| 能力              | 说明                                           |
| ----------------- | ---------------------------------------------- |
| 智能对话          | 输入问题后回答以流式方式逐字返回               |
| 知识库问答        | 提问前可选择知识库，让回答基于指定知识库的内容 |
| 对话历史          | 保留历史会话，可切换查看                       |
| 重命名 / 删除对话 | 管理自己的历史会话                             |

**提示**：AI 问答需要后端已接入 AI 服务；若未选择知识库，则由 AI 服务按通用能力回答。
