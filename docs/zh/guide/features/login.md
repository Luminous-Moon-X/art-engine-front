# 登录与认证

## 功能概述

提供账号密码登录、图形化人机校验、多租户选择登录、登录状态维持、密码修改与强制改密、退出登录、锁屏等完整认证能力。登录成功后由后端下发当前用户的角色、按钮权限与菜单，前端据此渲染可见的菜单与操作按钮。

## 登录

登录页左侧为产品介绍，右侧为登录表单（滑块验证在本地完成，用于防止误操作与自动化提交）：

| 表单项      | 说明                                               |
| ----------- | -------------------------------------------------- |
| 租户        | 仅在后端开启多租户时显示，选择要登录的租户后再登录 |
| 账号 / 密码 | 必填，密码由后端加密校验                           |
| 滑块验证    | 按住滑块拖到最右侧，提示「验证成功」后即可提交     |
| 记住密码    | 默认勾选，勾选后下次打开自动填充账号密码           |

演示账号（密码均为 `123456`）：

| 角色       | 账号    | 可见范围                       |
| ---------- | ------- | ------------------------------ |
| 超级管理员 | `Super` | 全部功能                       |
| 管理员     | `Admin` | 不含角色、菜单、租户等敏感功能 |
| 普通用户   | `User`  | 基础功能                       |

登录成功后会依次完成：保存登录凭证 → 拉取当前用户信息（角色、按钮权限、所属租户）→ 按权限生成菜单 → 跳转首页；如果是被拦截后跳转到登录页的，会自动回到原来要访问的页面。

- 登录失败：页面右上角弹出后端返回的错误提示
- 后端返回需要修改密码（如首次登录、密码过期）时，会直接弹出修改密码窗口，未完成修改前不能进入系统

## 修改密码

顶部导航栏 → 头像 → 「修改密码」，填写原密码、新密码、确认密码，提交成功后系统自动退出登录，需要用新密码重新登录。

## 退出登录

顶部导航栏 → 头像 → 「退出登录」，清除本地登录状态并返回登录页。

## 锁屏

- 触发方式：快捷键 `Alt` + `` ` ``（反引号）
- 锁屏：确认头像与用户名，设置锁屏密码后点击「锁定」，锁屏期间会屏蔽右键、F12 等常用快捷键
- 解锁：在全屏解锁页输入解锁密码后点击「解锁」；也可以点击「返回登录」直接退出登录
