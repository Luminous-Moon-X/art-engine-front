# 租户管理

## 功能概述

面向 SaaS 场景的多租户能力：平台方可以创建并维护多个租户，每个租户拥有独立的账号、组织、角色与权限数据；租户可开通的功能范围由「租户套餐」统一控制。

多租户是否启用、默认租户是谁，由后端配置决定；未开启多租户时，登录页与顶栏都不会出现租户相关入口。

## 租户信息字段

| 字段       | 说明                                   |
| ---------- | -------------------------------------- |
| 租户编码   | 租户的唯一标识，编辑时不可修改         |
| 租户名称   | 租户显示名称                           |
| 租户套餐   | 该租户可使用的功能范围                 |
| 租户管理员 | 租户的管理员账号，新增租户时可一并创建 |
| 到期时间   | 租户的到期日期                         |
| 启用状态   | 禁用后该租户下的账号无法登录           |
| 备注       | 补充说明                               |

## 页面操作

| 操作     | 说明                                                               |
| -------- | ------------------------------------------------------------------ |
| 查询     | 按租户名称、租户编码、所属套餐筛选                                 |
| 新增租户 | 填写租户信息并指定套餐与管理员账号                                 |
| 编辑     | 修改套餐、到期时间、启用状态等信息                                 |
| 删除     | 删除租户                                                           |
| 启用状态 | 在编辑租户时设置（列表中以标签展示），禁用后该租户下的账号无法登录 |

## 租户套餐

套餐用于批量圈定租户可用的功能范围，超管在「租户套餐」中维护：

| 字段            | 说明                                           |
| --------------- | ---------------------------------------------- |
| 套餐名称        | 套餐显示名称                                   |
| 菜单权限        | 勾选该套餐包含的菜单与功能权限，支持全选与展开 |
| 菜单数量        | 已勾选的菜单数量                               |
| 启用状态 / 备注 | 套餐的状态与说明                               |

**说明**：套餐中不勾选任何菜单表示不做限制（即拥有全部功能）。租户套餐的粒度到功能权限一级，勾选的菜单会作为该租户可用功能的依据。

## 切换租户

开启多租户后有两种切换方式：

- **登录时选择**：登录页的「租户」下拉中选择要登录的租户
- **登录后切换**：顶栏右上角的租户切换入口，仅超级管理员可见

## 权限说明

租户管理与租户套餐仅超级管理员可操作。
