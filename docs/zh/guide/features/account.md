# 账号管理

## 功能概述

对系统账号进行全生命周期管理：新增账号、编辑资料、分配角色与所属组织、启用 / 禁用、重置密码、删除账号，并可按组织（部门）筛选查看。

## 页面操作

页面左侧是组织树，右侧是账号列表。

| 项          | 内容                                                                |
| ----------- | ------------------------------------------------------------------- |
| 搜索条件    | 用户名称、用户名，可结合状态、手机号、邮箱等条件查询                |
| 列表列      | 用户名称、用户名、性别、手机号、邮箱、创建时间、启用状态、操作      |
| 新增 / 编辑 | 打开表单弹窗填写账号信息                                            |
| 重置密码    | 二次确认后把该账号密码重置为系统默认密码                            |
| 删除        | 二次确认后删除账号（提示操作不可恢复）                              |
| 启用状态    | 列表中以标签展示账号状态，在新增 / 编辑时设置，禁用后该账号无法登录 |

## 账号信息字段

| 字段               | 说明                               |
| ------------------ | ---------------------------------- |
| 用户名             | 登录账号，编辑时不可修改           |
| 名称               | 显示用的昵称                       |
| 所属部门           | 归属的组织节点，取自组织管理       |
| 角色               | 可多选，决定该账号的菜单与按钮权限 |
| 邮箱 / 电话 / 地址 | 联系方式                           |
| 性别               | 取自数据字典                       |
| 是否启用           | 关闭后账号不可登录                 |
| 个人介绍 / 标签    | 个人中心的展示信息                 |

## 权限说明

- 账号管理默认对超级管理员与管理员开放；菜单、角色、租户等敏感功能仅超级管理员可见
- 新增、编辑、删除、重置密码分别对应独立的功能权限，没有权限时按钮不显示

## 与其他模块的关系

- **组织管理**：账号必须归属于一个组织节点，组织树同时用于按组织筛选账号
- **角色管理**：账号通过角色获得权限，一个账号可以有多个角色
- **日志管理**：账号的登录行为会记录在登录日志中
