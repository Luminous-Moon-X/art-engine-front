# 个人中心

## 功能概述

当前登录账号的自助维护入口，用于更新个人资料与修改登录密码。

进入方式：顶部导航栏 → 头像 → 「个人中心」。该页面不在菜单中显示。

## 页面内容

| 区域         | 内容                                                             |
| ------------ | ---------------------------------------------------------------- |
| 左侧名片     | 头像、用户名、个人介绍、邮箱、手机、地址、个人标签               |
| 右侧基本信息 | 用户名（只读）、昵称、性别、邮箱、手机、地址、个人介绍、个人标签 |

点击「编辑」进入修改状态，调整后保存即可生效；「取消」放弃本次修改。

## 修改密码

顶部导航栏 → 头像 → 「修改密码」，填写原密码、新密码、确认密码，提交成功后系统会自动退出登录，需要用新密码重新登录。

如果是首次登录或被管理员重置密码，登录后系统会直接要求先修改密码。

## 相关说明

- 个人资料中的昵称、邮箱、手机等信息会展示在顶栏用户菜单与个人名片中
- 个人标签可以为空，用于标识岗位、职责等信息
