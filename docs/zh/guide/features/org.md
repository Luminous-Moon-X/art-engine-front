# 组织管理

## 功能概述

以树形结构维护企业的组织架构（部门），支持任意层级的上下级关系，作为账号归属、按组织筛选数据的依据。

## 组织信息字段

| 字段              | 说明                             |
| ----------------- | -------------------------------- |
| 部门名称          | 组织节点名称                     |
| 上级部门          | 父级组织，为空时表示顶级组织     |
| 排序              | 同级节点的显示顺序               |
| 负责人            | 该组织的负责人                   |
| 负责人电话 / 邮箱 | 负责人的联系方式                 |
| 是否启用          | 停用后该组织不再出现在选择列表中 |

## 页面操作

| 操作         | 说明                             |
| ------------ | -------------------------------- |
| 查看组织树   | 树形展示全部组织层级             |
| 新增下级组织 | 在指定节点下新增子组织           |
| 编辑         | 修改组织名称、负责人、排序等信息 |
| 删除         | 删除组织节点                     |

## 相关能力

- **组织树选择**：账号管理中的「所属部门」、按组织筛选列表时，都使用同一棵组织树
- **账号归属**：每个账号归属一个组织节点，组织变更后账号的归属关系同步更新
