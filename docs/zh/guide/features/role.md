# 角色管理

## 功能概述

维护系统中的角色，角色是权限分配的基本单位：账号通过绑定角色获得对应的菜单与操作权限。

## 角色信息字段

| 字段     | 说明                                           |
| -------- | ---------------------------------------------- |
| 角色名称 | 角色的显示名称                                 |
| 角色编码 | 角色的唯一标识（如 `R_SUPER`），编辑时不可修改 |
| 角色描述 | 角色的职责说明                                 |
| 是否启用 | 停用后该角色不再生效                           |
| 创建时间 | 角色创建时间，可按时间排序                     |

## 页面操作

| 操作     | 说明                                       |
| -------- | ------------------------------------------ |
| 查询     | 按角色名称、角色编码筛选                   |
| 新增角色 | 填写角色名称、编码、描述与启用状态         |
| 编辑     | 修改角色名称、描述与启用状态（编码不可改） |
| 删除     | 二次确认后删除角色                         |

## 角色与权限

- 角色的功能权限（可以看到哪些菜单、可以用哪些按钮）在[功能权限管理](./permission)页面中按角色勾选
- 一个账号可以绑定多个角色，最终权限为各角色权限的汇总
- 系统内置三个角色：超级管理员（`R_SUPER`）、管理员（`R_ADMIN`）、普通用户（`R_USER`）

**提示**：角色管理仅超级管理员可见；内置角色的编码建议保留，以免影响后端内置逻辑。
