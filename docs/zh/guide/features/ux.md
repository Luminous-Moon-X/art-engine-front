# 界面与通用操作

## 界面组成

登录后的界面由四部分组成：左侧菜单栏、顶部导航栏、多标签页、内容区。菜单由登录后从后端下发的权限决定，没有权限的功能不会出现。

## 顶部导航栏

| 位置 | 元素 | 说明 |
| --- | --- | --- |
| 左 | Logo / 系统名称 | 点击回到首页 |
| 左 | 折叠菜单 / 刷新 / 快速入口 / 面包屑 | 收起菜单、刷新当前页、快速打开常用功能、查看页面层级 |
| 右 | 搜索 | 全局菜单搜索，快捷键 `Ctrl` / `⌘` + `K` |
| 右 | 租户切换 | 开启多租户且为超级管理员时显示 |
| 右 | 全屏 / 语言 | 浏览器全屏；在简体中文与 English 间切换 |
| 右 | 通知 | 消息面板（通知 / 消息 / 代办），可标为已读 |
| 右 | AI 对话 | 打开智能问答窗口，详见[知识库与 AI 问答](./knowledge) |
| 右 | 设置 / 明暗切换 | 打开外观设置抽屉；切换浅色与暗黑模式 |
| 右 | 头像 | 个人中心、修改密码、退出登录 |

## 外观设置

点击顶栏右侧「设置」图标打开设置抽屉，修改即时生效：

| 分组 | 可配置项 | 默认值 |
| --- | --- | --- |
| 主题风格 | 浅色 / 暗黑 / 跟随系统 | 跟随系统 |
| 系统主题色 | 多种预设主题色 | 默认主题色 |
| 菜单布局 | 左侧、顶部、顶部 + 左侧、双栏 | 左侧 |
| 菜单风格 | 设计、亮色、暗色 | 设计 |
| 盒子样式 | 边框模式 / 阴影模式 | 边框模式 |
| 容器宽度 | 全屏 / 固定宽度 | 全屏 |
| 标签页样式 | 默认 / 卡片 / 谷歌 | 默认 |
| 页面动画 | 无、淡入淡出、左滑入、下滑入、上滑入 | 左滑入 |
| 圆角 / 菜单宽度 | 全局圆角、菜单展开宽度 | 0.75 / 215 |
| 基础开关 | 多标签栏、菜单手风琴、折叠按钮、快速入口、刷新按钮、面包屑、多语言、进度条、色弱模式、全局水印 | 前七项为开，后三项为关 |

设置抽屉底部提供「复制配置」与「重置配置」。

## 多标签页

开启多标签栏后，访问过的页面会以标签形式排列：

- 关闭标签：点击标签上的关闭按钮（只有一个标签时不显示）
- 右键菜单：刷新、固定 / 取消固定、关闭左侧、关闭右侧、关闭其他、关闭全部
- 固定标签（首页、工作台）不参与批量关闭
- 标签过多时支持滚轮横向滚动，切换页面会自动定位到可见位置

## 列表与表单通用操作

系统内所有管理页面共用同一套交互，熟悉一个页面即可通用：

| 区域 | 操作 |
| --- | --- |
| 搜索栏 | 填写条件后「查询」，或「重置」清空；条件多时可展开 / 收起 |
| 工具栏 | 搜索栏显隐、刷新、密度（紧凑 / 默认 / 宽松）、全屏、列设置、显示设置（斑马纹、边框、表头背景） |
| 列设置 | 勾选列显示隐藏、拖动调整列顺序 |
| 分页 | 每页 10 / 20 / 30 / 50 / 100 条，支持页码与跳页，翻页后回到表格顶部 |
| 批量操作 | 勾选数据后批量按钮显示已选数量；删除等危险操作会二次确认 |
| 表单 | 必填校验、重置；新增与编辑共用表单，编辑时关键字段（用户名、编码等）不可修改 |
| 状态记忆 | 表格外观偏好会保留；开启页面缓存的页面在标签关闭前保留查询条件与分页 |

## 示例页面

除上述业务功能外，系统还内置了大量美观实用的示例页面 Demo（数据看板、模板中心、组件中心、功能示例、结果页与异常页等），用于展示界面效果与交互写法。这些页面的数据多为演示数据，可作为二次开发时的参考。
