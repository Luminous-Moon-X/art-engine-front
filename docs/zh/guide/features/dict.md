# 数据字典

## 功能概述

统一维护系统中的枚举数据（下拉选项、状态标签等），供各业务模块直接引用，避免在代码中硬编码。字典分为两层：**字典类型**（一组枚举的定义）与**字典项**（组内的具体选项）。

## 字典（字典类型）

| 字段     | 说明                       |
| -------- | -------------------------- |
| 字典名称 | 中文名称，例如「用户性别」 |
| 字典编码 | 业务引用时的唯一标识       |
| 字典类型 | 字典的分类标识             |
| 是否启用 | 停用后业务中不再使用该字典 |
| 备注     | 补充说明                   |

支持按字典名称、字典编码、字典类型等条件查询，并提供新增、编辑、删除操作。

## 字典项

在字典类型下维护具体选项：

| 字段     | 说明                                             |
| -------- | ------------------------------------------------ |
| 字典标签 | 显示给用户的文案，例如「男」                     |
| 字典值   | 实际存储的值，例如 `1`                           |
| 显示样式 | 以标签展示时的颜色：默认、信息、成功、警告、危险 |
| 排序     | 选项显示顺序                                     |

同一个字典下可维护多个字典项，支持新增、编辑、删除；字典项变更后，业务页面中的下拉选项与标签展示随之更新。

## 典型用途

- **表单下拉**：账号管理中的性别、文章类型等选择项
- **状态标签**：列表中以不同颜色的标签展示状态
- **统一维护**：新增一种状态时只需在字典中配置，无需修改代码
