# 功能权限管理

## 功能概述

系统采用「菜单 + 按钮」两级权限模型：**菜单**决定能看到哪些页面，**按钮**（功能点）决定页面里能做哪些操作，每个功能点都有一个唯一的**权限标识**。管理员通过「功能权限」页面把功能点授权给角色、部门或用户。

## 权限模型

| 概念     | 说明                                     | 示例                             |
| -------- | ---------------------------------------- | -------------------------------- |
| 菜单     | 一级 / 多级菜单与页面                    | 系统管理、账号管理               |
| 按钮     | 页面内的功能点，不显示在菜单中           | 新增、编辑、删除、导出、重置密码 |
| 权限标识 | 功能点的唯一编码，后端校验、前端控制显隐 | `system:user:add`                |

## 菜单维护

在「菜单管理」中维护整个系统的菜单与功能点，以树形表格展示：

| 项       | 内容                                                  |
| -------- | ----------------------------------------------------- |
| 搜索条件 | 菜单名称、路由地址                                    |
| 列表列   | 菜单名称、菜单类型、排序、路由地址、状态、操作        |
| 操作     | 新增菜单、一键展开 / 收起、行内新增子菜单、编辑、删除 |

菜单类型包括目录、菜单、按钮、内嵌页面、外链。菜单的基本信息包含：

| 字段 | 说明 |
| --- | --- |
| 菜单类型 | 目录 / 菜单 / 按钮 / 内嵌 / 外链 |
| 菜单名称 | 菜单或功能点的名称 |
| 路由地址 | 页面访问路径 |
| 组件路径 | 页面组件位置（后端按该路径加载页面） |
| 权限标识 | 功能权限编码，如 `system:user:add` |
| 图标 / 排序 | 菜单图标与显示顺序 |
| 外链地址 / 激活路径 | 外链菜单与高亮归属 |
| 其他开关 | 是否启用、是否缓存页面、是否隐藏、是否内嵌、是否显示徽章、是否固定标签页、是否隐藏标签页、是否全屏 |

按钮类型的菜单只需要填写三项：权限名称、权限标识、排序。

## 功能授权

「功能权限」页面用于把功能点授权给具体的对象：

1. 在左侧选择授权主体，支持**角色**、**部门**、**用户**三种（分别以树形展示，用户树中不包含超级管理员）
2. 在右侧的功能树中勾选该主体可以使用的菜单与按钮（首页不参与授权）
3. 点击「保存」提交；未选择授权主体时会提示先选择主体

**说明**：按部门授权适合「整个部门使用同一批功能」的场景，按用户授权适合处理个别账号的例外情况；三种主体的授权结果最终会体现在该账号的菜单与按钮上。

## 权限如何生效

| 环节     | 表现                                                               |
| -------- | ------------------------------------------------------------------ |
| 登录后   | 后端下发当前账号的角色、按钮权限与菜单，前端据此渲染               |
| 菜单级   | 没有权限的菜单不显示；直接输入地址访问无权限页面时会被重定向回首页 |
| 按钮级   | 没有权限的按钮不显示，后端同样会校验，防止绕过前端直接调用接口     |
| 租户套餐 | 租户可用的功能范围按权限标识圈定，见[租户管理](./tenant)           |

## 常见权限标识

| 模块 | 权限标识 |
| --- | --- |
| 账号管理 | `system:user:add`、`system:user:edit`、`system:user:delete`、`system:user:resetPassword` |
| 组织管理 | `system:dept:add`、`system:dept:edit`、`system:dept:delete` |
| 角色管理 | `system:role:add`、`system:role:edit`、`system:role:delete` |
| 功能授权 | `system:menu-permission:edit` |
| 文件管理 | `system:oss-config:add/edit/delete/enable`、`system:oss-file:upload/download/delete` |
| 日志管理 | `system:login-log:delete`、`system:api-log:delete`、`system:menu-log:delete` |
