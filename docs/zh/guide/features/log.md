# 日志管理

## 功能概述

系统会记录三类运行日志，用于安全审计与问题排查：登录日志、菜单日志、接口日志。三类日志相互独立，各自支持按条件检索与删除。

## 登录日志

记录每一次登录尝试的时间、来源与结果。

| 项       | 内容                                                              |
| -------- | ----------------------------------------------------------------- |
| 搜索条件 | 用户名、昵称、登录 IP、登录状态、时间范围                         |
| 列表列   | 用户名、昵称、登录 IP、浏览器、操作系统、登录时间、状态、提示信息 |
| 操作     | 查看、删除                                                        |

可以用它排查「某个账号在什么时间、用什么设备、从哪里登录，是否成功」。

## 菜单日志

记录用户对菜单（页面）的点击行为。

| 项       | 内容                                       |
| -------- | ------------------------------------------ |
| 搜索条件 | 用户名、昵称、菜单名称、菜单路径、时间范围 |
| 列表列   | 用户名、昵称、菜单名称、菜单路径、点击时间 |
| 操作     | 查看、删除                                 |

可以用它了解各功能的使用频率，为功能优化提供依据。

**说明**：菜单日志由系统在页面切换时自动上报，不需要人工操作。

## 接口日志

记录后端接口的调用情况，是排查接口异常的主要依据。

| 项       | 内容                                                     |
| -------- | -------------------------------------------------------- |
| 搜索条件 | 用户名、昵称、请求 URL、请求方法、响应码、时间范围       |
| 列表列   | 用户名、昵称、操作描述、请求 URL、响应码、耗时、请求时间 |
| 详情     | 请求方法、来源 IP、请求参数、返回值（JSON）              |
| 操作     | 详情、删除                                               |

**限制说明**：日志列表的「批量删除」按钮当前不可用（表格未开启勾选列，无法选中数据），需要删除时请使用每行的「删除」。

## 权限说明

三类日志的删除操作分别对应独立权限：`system:login-log:delete`、`system:api-log:delete`、`system:menu-log:delete`。
