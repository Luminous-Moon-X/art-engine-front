# 文件管理

## 功能概述

统一的对象存储（OSS）文件管理：集中配置云存储服务，并提供文件的上传、浏览、下载与删除能力，业务中的图片、文档等附件都通过这里管理。

## 对象存储配置

维护可用的存储服务配置：

| 字段                    | 说明                                       |
| ----------------------- | ------------------------------------------ |
| 配置名称                | 便于识别的名称，如「阿里云 OSS」           |
| 服务地址                | 存储服务的 Endpoint                        |
| Access Key / Secret Key | 访问密钥；编辑时 Secret Key 留空表示不修改 |
| 桶                      | 存储空间名称（Bucket）                     |
| 是否启用                | 启用后该配置生效                           |
| 备注                    | 补充说明                                   |

支持按配置名称、桶与启用状态查询，以及新增、编辑、删除。

**说明**：同一时间只有一套配置生效，启用某个配置时其他已启用的配置会自动被禁用。

## 文件列表

| 项       | 内容                                   |
| -------- | -------------------------------------- |
| 搜索条件 | 文件名称                               |
| 列表列   | 文件名称、内容类型、文件大小、上传时间 |
| 上传     | 选择上传路径（目录）与文件后上传       |
| 下载     | 下载文件到本地                         |
| 删除     | 删除文件                               |

## 权限说明

| 能力 | 权限标识 |
| --- | --- |
| 配置增删改与启用 | `system:oss-config:add`、`system:oss-config:edit`、`system:oss-config:delete`、`system:oss-config:enable` |
| 文件上传 / 下载 / 删除 | `system:oss-file:upload`、`system:oss-file:download`、`system:oss-file:delete` |

## 与其他模块的关系

- **知识库**：知识库封面与知识库中上传的文档都保存在对象存储中
- **业务附件**：其他模块需要上传图片、附件时，统一使用这里的存储配置
